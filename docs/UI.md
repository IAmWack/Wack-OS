# Wack-OS — интерфейс

Интерфейс — не украшение поверх логики, а отдельный слой со своими
правилами. Здесь описано, как он устроен и куда что дописывать.

## Из чего собран

```
components/wackos_gfx/     рисование: кадровый буфер, примитивы, шрифт
master/main/theme.{h,c}    палитры (переключаются на лету) и геометрия экрана
master/main/astolfo.{h,c}  персонаж как состояние системы
master/main/ui.{h,c}       роутер экранов, обои, шапка, строка подсказок, ввод
master/main/ui_widgets.c   общие виджеты: карточка, список, иконки, облачко
master/main/screens/       по файлу на экран
master/main/settings.{h,c} яркость, громкость, тема, показывать ли персонажа
master/main/sound.{h,c}    звуки (пищалки пока нет — слой молчит)
```

Рисование отделено от железа: весь UI кладёт пиксели в кадровый буфер
172x320 RGB565, а `display_flush()` отправляет его либо в ST7789, либо в
окно симулятора. Поэтому картинка на ноутбуке совпадает с будущей
картинкой на матрице пиксель в пиксель (см. [`sim/README.md`](../sim/README.md)).

Шрифт — растровый, 4 бита альфы на пиксель, три начертания (11/14/22 px),
с латиницей, кириллицей и парой пиктограмм. Генерируется из обычного
TTF скриптом `tools/gen_font.py` (`make font` в `sim/`), в прошивке
занимает ~28 КБ.

## Экраны и навигация

| Экран      | Что показывает                                              |
|------------|--------------------------------------------------------------|
| boot       | загрузка: каждый шаг — реальный запрос к slave, прогресс сердечками |
| menu       | четыре раздела + Астольфо с репликой                         |
| modules    | список модулей, которые о себе сообщил slave (`UI_MENU_GET`)  |
| module     | результат выбранного модуля (`UI_MENU_SELECT`) и время ответа |
| slave      | состояние связи, адрес, версии, RTT + действия (пинг, reset)  |
| settings   | яркость, громкость, тема, персонаж                           |
| about      | версии и немного милоты                                      |

Навигация — стек: `ui_goto()` уходит вглубь, `ui_back()` возвращается,
`ui_replace()` меняет экран без возврата (нужен загрузке). Глубина
ограничена `NAV_DEPTH`.

Экран — это структура `ui_screen_t` из четырёх функций:

- `enter()` — вызвали при переходе;
- `draw(t)` — **только рисование**;
- `tick(t)` — логика сама по себе (шаги загрузки, опросы);
- `input(in)` — реакция на энкодер.

Важное правило: из `draw()` нельзя ходить к slave. Запрос показывает
"думаю" и сам перерисовывает кадр — вызов логики из отрисовки уходит в
бесконечную рекурсию (на этом уже наступили, в `render()` стоит защита).

### Добавить экран

1. Положить файл в `master/main/screens/`.
2. Описать `const ui_screen_t screen_<имя> = {...}`.
3. Добавить его в `screen_id_t` и в таблицу `SCREENS[]` в `ui.c`.
4. Вписать файл в `master/main/CMakeLists.txt` и в `UI_SRCS` в `sim/Makefile`.

## Ввод

Одна ручка KY-040 — три жеста:

| Жест              | Действие                                            |
|-------------------|------------------------------------------------------|
| поворот           | листать список; чем быстрее крутишь, тем крупнее шаг |
| короткое нажатие  | выбрать / выполнить / войти в правку значения        |
| долгое (>0.6 с)   | назад                                                |

Ускорение прокрутки считает `ui.c` по времени между щелчками, экраны об
этом не знают. Длинное нажатие определяет `encoder.c` по обоим фронтам
кнопки.

## Астольфо

Персонаж рисуется кодом из примитивов (`astolfo.c`) — ни PNG, ни SD, ни
декодера, и на любом размере получается чисто. По канону Fate/Apocrypha:
пастельно-розовые волосы, толстая коса с чёрной лентой, фиолетовые
глаза, тёмный костюм с бело-розовым плащом.

Настроение — это состояние системы, а не картинка:

| Настроение | Когда                                  |
|------------|-----------------------------------------|
| `idle`     | обычное состояние, моргает и дышит      |
| `thinking` | идёт запрос к slave                     |
| `happy`    | slave ответил                           |
| `sad`      | slave молчит или вернул ошибку          |
| `sleep`    | минута без действий пользователя        |

Переключает настроение слой логики (`app_logic.c`), а `astolfo_tick()`
сам возвращает персонажа в `idle` и уводит в сон. Посмотреть все
настроения разом: `make sheet` в `sim/`.

## Темы

Палитра живёт в структуре `wackos_theme_t`, а не в `#define`, — ровно
ради экрана настроек: тема меняется в следующем же кадре. Сейчас три
(розовая, лаванда, мята), добавить четвёртую = дописать строку в массив
`THEMES[]` в `theme.c`.

Цвета персонажа в тему не входят: тема — настроение корпуса, Астольфо
всегда Астольфо.

## Что ещё не сделано

- Настройки не переживают перезагрузку (нужен NVS).
- Звук молчит, пока `PIN_BUZZER` = -1: пищалки на макете нет.
- Длинные операции (`REQ` → `RES OK ACCEPTED` → поток `EVT`) в UI ещё не
  показываются — для них нужен экран с прогрессом и приёмом событий.
- Картинка-фон вместо нарисованных обоев (если захочется настоящий арт).
