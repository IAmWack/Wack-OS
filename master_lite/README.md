# wack-os lite

Автономная прошивка для ESP32-S3 — "мультитул" в духе смарт-часов: экран,
маскот с темами, microSD, Bluetooth HID-пульт, заряд батареи и слот под
датчики. Независимая ветка проекта [Wack-OS](..): никакого UART/протокола
к второй плате (`slave/`) — всё внутри одной прошивки.

## Железо

- **Плата:** Waveshare ESP32-S3-LCD-1.47 (ST7789 172×320 SPI, встроенный
  слот microSD 4-бит SDMMC, кнопки BOOT/RST на борту).
- **Энкодер KY-040** — пины заведены (`board_pins.h`), но физически ещё
  не распаян: пока вместо него жесты кнопкой BOOT (`boot_button.c`) —
  одно короткое нажатие листает вниз, два коротких — вверх, долгое — клик.
- **Батарея** — LiPo через штатный JST-разъём платы (VBAT), заряд читается
  ADC напрямую, без внешнего делителя.
- **MPU6050** (акселерометр/гироскоп) — драйвер по I2C уже готов
  (`mpu6050.c`), ждёт, пока датчик физически появится на макете.

> ⚠️ **Грабля с подсветкой:** в документации и официальной демо-прошивке
> Waveshare для этой платы пин подсветки (`PIN_LCD_BL`) указан как
> GPIO48. На нашем экземпляре платы реально работает **GPIO46** — судя по
> всему, расхождение партий/ревизий. Если экран остаётся чёрным при
> рабочей SPI-логике без ошибок в логах — проверьте подсветку отдельным
> тестом (голый GPIO HIGH/LOW), не доверяя документации вслепую.

## Возможности

- Экран-циферблат с портретом маскота (переключается темой), меню,
  настройки, просмотр файлов с SD, BLE HID-пульт (клавиатура/мышь),
  скан BLE-устройств поблизости.
- Индикатор заряда батареи — по центру шапки интерфейса, между "ушками"
  над логотипом (если VBAT подключён к ADC).
- Программное "выключение" (`power.c`) — пункт меню "Выключить" гасит
  подсветку и уводит в deep sleep, будит кнопка BOOT. Физический
  слайд-переключатель PWR на плате работает отдельно, без участия
  прошивки.

## Сборка и прошивка

Нужен ESP-IDF v6.1 (target `esp32s3`):

```sh
source /path/to/esp-idf/export.sh
idf.py build
idf.py -p /dev/ttyACM0 flash monitor
```

## Статус / план

- Тачскрина на этой плате нет — проверено сканом I2C по пинам, заявленным
  в справочной распиновке (ничего не отозвалось; те же GPIO к тому же уже
  заняты под SPI-экран на этом экземпляре платы).
- Следующим шагом — физические кнопки (взамен/в дополнение к BOOT-жестам)
  и инструменты поверх готового драйвера MPU6050.
