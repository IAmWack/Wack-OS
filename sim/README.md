# Симулятор экрана master

Окно на ноутбуке вместо платы master: то же меню, тот же рендер,
тот же протокол. Нужен, чтобы доводить интерфейс, пока железа нет
под рукой.

```
make          # собрать (нужны только gcc и libX11 — они уже есть)
./wackos-sim  # запустить окно с фальшивым slave в памяти
```

ESP-IDF для симулятора не нужен.

## С живой платой slave

Если slave подключён по USB, симулятор говорит с ним по-настоящему —
меняется только транспорт, весь UI и протокол те же:

```
./wackos-sim -p /dev/ttyUSB0        # интерфейс на живых данных
./wackos-sim -p /dev/ttyUSB0 -v     # плюс кадры REQ/RES в терминал
make test PORT=/dev/ttyUSB0         # прогон проверок по железу
```

Клавиши `O` (обрыв) и `L` (лаг) в этом режиме не работают: провод
настоящий, обрыв изображается выдёргиванием USB. Порт занимается
монопольно — закройте монитор порта в IDE, иначе байты будут делиться
пополам. Плата после перетыкания любит переехать с `ttyUSB0` на
`ttyUSB1` — если порт не открылся, симулятор покажет список доступных.

### Настоящая ручка

Если к slave подключён энкодер (см. `slave/main/modules/module_encoder.h`),
интерфейс в окне слушается **его**, а не клавиатуры: щелчки приезжают
кадрами `EVT ENC` и попадают в тот же слой ввода. Клавиатура при этом
продолжает работать — удобно крутить ручкой, а редкие действия жать
с клавиш. Нарисованная в окне ручка поворачивается вместе с настоящей.

## Управление

| Клавиша            | Что делает                                   |
|--------------------|-----------------------------------------------|
| колесо мыши, ↑/↓   | крутить энкодер                               |
| Enter, пробел, ЛКМ | короткое нажатие (выбрать)                    |
| Backspace, ПКМ     |长 длинное нажатие (назад)                      |
| `O`                | отключить/подключить slave (обрыв провода)    |
| `L`                | залипающий провод: задержка 6 мс ↔ 120 мс     |
| `S`                | снимок экрана в `wackos-screen-NN.ppm`        |
| `Q`, Esc           | выход                                         |

Ключи запуска: `-s N` — масштаб пикселя (1..4; по умолчанию берётся
максимальный, который влезает в экран), `-v` — печатать каждый кадр
протокола `REQ`/`RES` в терминал.

## Что настоящее, а что подменено

Подменены ровно три нижних слоя — те, за которыми железо:

| Слой       | На плате                   | В симуляторе                     |
|------------|-----------------------------|-----------------------------------|
| экран      | `master/main/display.c` (ST7789 по SPI) | `sim_display.c` (окно X11) |
| энкодер    | `master/main/encoder.c` (ISR на KY-040) | `sim_encoder.c` (клавиатура/мышь) |
| транспорт  | `master/main/uart_transport.c`          | `sim_transport.c` (петля в памяти) |

Звук тоже подменён: `sim_sound.c` печатает в терминал то, что на плате
пропищит пищалка.

Всё остальное — тот же код, что уедет в прошивку:

- `master/main/ui.c`, `ui_widgets.c`, `screens/` — экраны, навигация,
  списки, анимация (см. [`docs/UI.md`](../docs/UI.md));
- `master/main/astolfo.c`, `theme.c`, `settings.c` — персонаж, палитры,
  настройки;
- `master/main/app_logic.c` — что делать по выбору пункта;
- `components/wackos_gfx/` — весь рендер (кадровый буфер 172x320 RGB565);
- `components/wackos_protocol/` — кадры `REQ`/`RES`, тайм-ауты, ретраи;
- `slave/main/dispatcher.c` и его модули — **настоящий** диспетчер
  slave, так что меню и ответы в окне те же, что придут с живой платы.

Картинка в окне — честный кадровый буфер, увеличенный целыми
пикселями. Что видно на ноутбуке, то и будет на ST7789.

Слой протокола хранит состояние (счётчик `seq`, указатель на
транспорт) в статических переменных, а тут в одном процессе живут обе
стороны сразу — поэтому он собирается дважды, и у копии для slave все
имена переименованы (`SLAVE_DEFS` в Makefile). Это честнее, чем
писать фальшивый slave руками.

## Прогон проверок

```
make test                    # по фальшивому slave — быстрая проверка, что ничего не сломали
make test PORT=/dev/ttyUSB0  # по живой плате
```

`wackos-test` гоняет настоящий код master (протокол + логика + экраны)
против slave и проверяет то, что обещает
[`docs/PROTOCOL.md`](../docs/PROTOCOL.md): ответы команд, коды ошибок
для заглушек, реакцию на битую контрольную сумму, игнорирование чужого
адреса, время ответа, переживание перезагрузки платы. Заодно проходит
по экранам на живых данных и складывает кадры в `shots/live-*.ppm`.

Код возврата 0 — всё прошло, так что прогон годится и для CI.

## Снимки экрана без окна

```
make shots     # -> shots/*.ppm (+ .png, если установлен ImageMagick)
```

`wackos-shot` гоняет интерфейс по сценарию (загрузка, меню, модули,
настройки, смена темы, обрыв провода) и сохраняет кадры в файлы.
Работает без X-сервера — удобно по ssh и для сравнения "было/стало"
после правок оформления.

```
make sheet     # -> shots/astolfo-*.ppm: все настроения персонажа
```

## Где что менять

- цвета и размеры — `master/main/theme.{h,c}`;
- шапка, обои, подсказки, навигация — `master/main/ui.c`;
- содержимое конкретного экрана — `master/main/screens/screen_*.c`;
- персонаж — `master/main/astolfo.c`;
- примитивы рисования (сердечки, искорки, бантик, ушки) —
  `components/wackos_gfx/wackos_gfx.c`;
- шрифт — `tools/gen_font.py` (`make font` перегенерирует таблицы из
  TTF; нужен python3 + Pillow).
